## CS 답변 적용 가이드

1. **건강기능식품 여부 문의** → 위의 식품유형 구분 참고
2. **성분/함량 문의** → 핵심 성분 섹션 인용
3. **복용법 문의** → 포장/섭취량 섹션 인용
4. **쿠팡-스마트스토어 상품명 매칭** → 성분·용량이 동일하면 같은 상품으로 간주 (see: cs_cross_channel_products.md)
5. **일반식품 상품 답변 시** → 효능 표현 절대 금지. "본 제품은 일반식품으로 건강기능식품·의약품이 아닙니다" 명시.
