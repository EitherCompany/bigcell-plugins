**절대 규칙: 뉴트리정 상품 CS 답변 작성 전, 반드시 `C:\Users\이더컴퍼니\Desktop\뉴트리정 서류\` 폴더의 해당 상품 견적서 PDF를 직접 열어 함량·성분·원산지·식품유형을 확인할 것.**

**Why:** 2026-04-29 사용자 강한 피드백. 사용자가 폴더 권한을 준 이유가 바로 "매 문의마다 견적서 함량 확인하고 그에 맞는 정확한 답변 작성"이었음. 메모리(`nutrijeong_product_ingredients.md`)는 추출 요약본이라 누락·과거 정보일 수 있어서 절대 단독 의존 금지. 메모리만 보고 답변하는 것은 사용자가 권한 부여한 의도 정면 위배.

**How to apply:**

1. **뉴트리정 관련 CS 문의 확인 시 즉시:**
   - 상품명 식별 (askText나 prdNo 매핑)
   - `C:\Users\이더컴퍼니\Desktop\뉴트리정 서류\` 폴더에서 해당 상품 견적서 PDF 찾기
   - PDF Read 도구로 직접 열어서 함량·성분·원산지 확인

2. **확인할 정보 (반드시):**
   - 핵심 성분 정확한 함량 (mg, %, μg)
   - 부원료 함량 (특히 비타민C, 미네랄 등 자주 문의되는 성분)
   - 원산지 (제조국)
   - 식품유형 (일반식품 vs 건강기능식품)
   - HACCP 여부
   - 1일 섭취량·횟수
   - 포장 단위

3. **메모리는 보조 자료로만:**
   - 메모리 = 빠른 참고용 요약
   - 견적서 PDF = 1차 권위 자료
   - 두 자료 충돌 시 PDF 우선
   - PDF에서 확인한 새 정보는 메모리도 업데이트

4. **PDF 없는 경우:**
   - 폴더에 견적서 PDF가 없으면 사용자에게 즉시 요청
   - "이 상품 견적서 PDF가 폴더에 없어서 정확한 함량 답변 어렵습니다. PDF 공유해 주세요"

5. **워크플로우 순서:**
   ```
   문의 확인 → 상품 식별 → 견적서 PDF 열기 → 함량/성분 확인
   → 답변 초안 작성 (PDF 데이터 기반) → 사용자 검수 → 저장 → 송신
   ```

**중요:** 이 규칙은 뉴트리정 모든 상품에 예외 없이 적용. 글루타치온, 멜라토닌, 마그네슘, 비타민B군 등 모두.
