사방넷 CS 처리는 "답변 저장"까지만 하는 게 아니라 **문의수집 → 답변 저장 → 답변 송신**까지 한 사이클로 전부 수행해야 한다.

**Why:** 2026-04-21 사용자 피드백. 오늘은 사용자가 문의수집과 답변송신 단계를 직접 보조했는데, 다음부터는 Claude가 이 단계들도 자동으로 수행해야 함. 중간 단계를 빼먹으면 실제로 고객에게 답변이 전달되지 않음.

**How to apply:**
1. **문의사항수집 페이지** (`/customer-service/ask-collect`) 접속
2. **모든 사업자에 대해 "쇼핑몰 문의수집" 버튼 클릭** — 사업자별로 순회하여 각 쇼핑몰(쿠팡/스마트스토어/등)의 최신 문의를 전부 끌어옴
3. 수집이 끝나면 **문의사항답변 페이지** (`/customer-service/ask-answer`)로 이동
4. 신규접수(division=001) 문의 조회 → 답변 초안 생성 → 사용자 검토/승인 → 답변 입력 → **화면저장**
5. 저장 완료 후 **"쇼핑몰 답변 송신"은 사용자가 직접 클릭** — Claude는 화면저장까지만 자동화하고, 송신 버튼은 사용자가 No 옆 체크박스 선택 후 직접 누름 (2026-04-27 사용자 피드백 반영)
6. 송신 성공 확인: `answTrnmDt`(답변송신일시)에 시각이 찍히고 `division`이 null로 변경되면 전송 완료

**핵심 워크플로우 (2026-04-28 update):**

**Claude가 풀 사이클 자동화:**
1. 문의수집 (모든 사업자) — 검색 + 모든 사업자 선택 + 쇼핑몰 문의수집 클릭
2. 신규접수 조회 → 답변 초안 작성 → **사용자에게 텍스트 체크 받기** (이게 검수 단계)
3. 승인 시 → 사방넷 textarea에 답변 직접 채워 넣기 (Vue $data.answText)
4. No 옆 체크박스로 행 선택 → **화면저장 버튼 클릭** (저장 완료 확인)
5. 검색 갱신 후 다시 행 선택 → **"쇼핑몰 답변송신" 버튼 클릭** — 송신까지 Claude가 자동 진행
6. 송신 성공 확인: `answTrnmDt`(답변송신일시)에 시각 찍히고 `division`이 null로 변경되면 완료

**왜 송신까지 자동화?**
- 2026-04-28 사용자 피드백
- 답변 텍스트 검수가 이미 사용자와 함께 끝난 상태이므로 "최종 컨트롤"은 검수 단계에서 행사된 것임
- 검수 → 저장 → 송신을 분리하면 사용자가 매번 버튼만 클릭해야 해서 비효율
- 답변 내용에 합의가 이뤄지면 이후 단계는 모두 자동화

**예외:** 사용자가 "이번 건은 내가 직접 보낼게" 같이 명시적으로 송신을 요청하면 그때만 화면저장까지만 진행
