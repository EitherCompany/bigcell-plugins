# CS 자동답변 스킬

## 개요

사방넷 관리자(sbadmin03.sabangnet.co.kr)에서 쿠팡/네이버 스마트스토어 고객 문의를 자동으로 수집하고,
상품 정보를 바탕으로 안전한 답변을 생성하여 저장·송신하는 스킬이다.

**핵심 원칙:**
- 과학적이거나 확신을 주는 답변은 절대 하지 않는다
- 애매모호하게 위험을 회피하는 답변을 한다
- 친절·공손한 톤(~합니다, ~드립니다)을 사용한다
- 사용자 첨삭을 축적하여 답변 품질을 지속 개선한다

## 사용자 정보 / 로그인

- 사방넷 로그인 ID: `eithercompany`
- 서비스코드: `159514`
- svcAcntId: `mw159514`
- **비밀번호는 이 파일에 저장하지 않는다.** 운영자가 사방넷에 직접 로그인하거나(브라우저 비밀번호 저장 권장),
  최초 1회 수동 로그인한 세션을 사용한다. 로그인이 만료되어 공개 사이트로 리디렉션되면 운영자에게
  로그인을 요청한다.

## 전체 워크플로우

**반드시 이 순서대로 진행한다:**

### Phase 1: 문의사항수집 (항상 먼저 실행)

1. \`#/customer-service/ask-collect\` 페이지로 이동
2. 전체 매출처(쇼핑몰) 체크박스를 선택한 뒤 "쇼핑몰 문의수집" 버튼 클릭하여 최신 문의를 수집
   (매출처를 선택하지 않으면 "문의 수집할 매출처를 선택해 주세요" 안내가 뜬다)
3. 수집 완료 대기 (LOADING 종료 후 "새로고침"으로 갱신, 각 쇼핑몰 상태가 "정상종료"가 될 때까지)
4. 미처리건수 확인 후 사용자에게 보고

### Phase 2: 문의사항답변

1. \`#/customer-service/ask-answer\` 페이지로 이동
2. 검색 필터 설정:
   - 처리구분: **"전체"(000)** 선택 후 검색 — 신규접수(001) 단독 필터는 누락 위험이 있어 사용하지 않는다
   - 기간: 적절히 설정 (기본 1주일)
   - 검색 실행 후, 처리상태(\`shmaAskProgStsCd\`)가 \`001\`인 건만 실제 미답변으로 판별
3. 미답변(001) 건이 0건이면 사용자에게 "미답변 문의가 없습니다" 보고 후 종료

### Phase 3: 각 문의별 답변 생성

신규접수(001) 문의 각각에 대해:

1. **문의 정보 파악** — askText(문의내용), shmaPrdNm(상품명)/shmaPrdNo(상품코드),
   shmaNm(쇼핑몰)/shmaCnctnLoginId(계정ID), shmaClctAskDivNm(문의유형)
2. **자가학습 데이터 + 메모리 참조 (웹검색 절대 금지)**
   - \`scripts/cs_answer_guidelines.json\` 가이드라인 참조
   - 플러그인 \`memory/\` 폴더 CS 메모리(템플릿 형식, disclaimer 조건, 상품 성분 레퍼런스) 참조
   - 웹검색으로 상품정보 조사 금지 (잘못된 정보 유입 위험)
   - 뉴트리정 함량은 메모리만 의존하지 말고 견적서 PDF 직접 확인
3. **답변 생성** (아래 가이드라인)
4. **사용자에게 초안 제시 후 확인** — 수정사항은 자가학습 데이터에 저장

### Phase 4: 답변 저장 및 송신

승인 시: tableData[i].ansText 입력 + textarea DOM 입력/이벤트 발행 → "화면저장"(001→002)
→ (확인 후) 체크박스 선택 → "쇼핑몰 답변송신"(→003) → 결과 보고

**예외 — 자동 송신하지 말 것:** 교환/재배송 일정, 쿠팡측 시스템 오류 관련 문의는 실제 주문/교환
상태 확인이 필요하므로 자동 답변하지 말고 사용자에게 확인 요청한다.

## 답변 생성 가이드라인

### 톤 & 스타일
존칭(~합니다/~드립니다), "안녕하세요, [브랜드명]입니다."로 시작,
"추가 문의사항이 있으시면 언제든 말씀해 주세요. 감사합니다."로 마무리

### 위험회피 원칙 (가장 중요)
금지: "효과가 있습니다", "치료/개선합니다", "100%/반드시", "임상 시험 결과", "의사가 추천"
안전: "개인차가 있을 수 있습니다", "참고 부탁드립니다", "전문가와 상담을 권장드립니다"

### 문의 유형별 패턴
- 상품 스펙/기능: 상품 페이지 기재 정보만, 모르면 "확인 후 안내"
- 불량/AS: 공감 우선 → 교환/반품 안내
- 배송: 배송 상황 확인 안내
- 건강식품(뉴트리정): 효능/효과 절대 금지, 효능 문의에만 "일반식품·의약품 아님" disclaimer
- 주관적(소리/냄새/촉감): "제품 특성상 개인차가 있을 수 있습니다"
- 실물 이슈(소비기한/파손/이물): 반품 전 톡톡/이메일로 사진 증빙 먼저 요청

### 쿠팡 CS문의 파싱
"▶ 고객 인입내용", "▶ 고객 요청사항"을 파싱하여 실제 문의 추출 후 답변

## 자가학습 시스템
- 데이터: \`scripts/cs_answer_guidelines.json\` (general_rules / product_specific / inquiry_type_patterns)
- 첨삭 시 적절한 카테고리에 저장 (중복 회피, 구체 예시, 원문 보존, 날짜 기록)
- **플러그인 설치 시 스킬 폴더가 읽기 전용이면** 첨삭은 운영자 영구 메모리(\`memory/\`)에 저장
