# 빅셀 일일보고서 v5 플러그인

이더컴퍼니 5개 이커머스 계정의 쿠팡/네이버 매출을 빅셀(app.bigcell.co.kr)에서 자동 수집하여 종합 HTML 일일보고서를 생성하는 플러그인.

## v5 포맷 핵심 특징 (필수)

- **5개 사업자 카드 비중 표시**: 각 카드에 매출 비중(%) + 순이익 비중(%) 프로그레스바
- **주간 차트 8일 범위**: 오늘 + 지난주 동일요일 포함 — 차트 양끝에서 시각적 비교
- **주간 차트 레이블 요일 포함**: `04/13(월)` 형식으로 MM/DD(한글요일) 표기
- **특이사항 섹션 번호 리스트**: 한눈요약 + 지난주 동일요일 대비 모두 ①②③… 번호 리스트
- **계정별 변동 표 색상 구분**: 전일 대비 컬럼(연주황 #fff3e0) / 지난주 대비 컬럼(연보라 #f3e5f5) + 가운데 정렬
- **소수점 보호 split**: 해석 문장의 `+1.8%`, `-57.5%` 같은 퍼센트 수치가 잘리지 않도록 regex 보호

## 트리거

사용자가 다음 중 하나를 언급하면 자동 실행:
- "빅셀 업데이트", "빅셀 일일", "빅셀 보고서"
- "매출분석 업데이트", "그로스 시트 업데이트"
- "일일 보고서", "매출 분석"

## 구성

- `skills/bigcell-daily-report/SKILL.md` — 7단계 파이프라인 정의
- `skills/bigcell-daily-report/scripts/` — 추출·생성·주입 스크립트
  - `integrated_bigcell.py` — 빅셀 대시보드/통계 페이지 크롤링 (Playwright) + 지난주 동일요일 보강
  - `rebuild_report.py` — v2 HTML 보고서 생성 (카드 비중 + 8일 차트)
  - `build_v3_report.py` — 스크린샷 삽입
  - `build_special_context.py` — 특이사항 수치 컨텍스트 생성 (전일/지난주 비교)
  - `inject_special_section.py` — 특이사항 HTML 주입 (번호 리스트 + 컬럼 색상 + 소수점 보호)
  - `capture_screenshots.py` — 대시보드 스크린샷 보관

## 배포 목적

3대 PC(마스터 개발 PC 1대 + 배포 수신 PC 2대)에서 동일한 v5 포맷 결과물이 나올 수 있도록 스킬 자체에 포맷 요구사항을 박아넣은 버전.
